GeoConvert — пересчёт координат (локальный сервис)

Ввод: N,E через запятую (разделитель целой и дробной части — точка). Excel: скопируйте 2 колонки (табуляция заменится на запятую). AutoCAD: выделите объекты, введите _list, скопируйте вывод целиком (X=N, Y=E).
N,E — исходные
N,E — результат
Копировать в AutoCAD:
#N (исх.)E (исх.)N (рез.)E (рез.)
Карта — точки результата (OpenStreetMap)
База: 543 проекции (ГЕОМОСТ/GEOBRIDGE, EPSG) · пересчёт: PROJ/pyproj · карта: OpenStreetMap/Leaflet (тайлы по сети, Яндекс API не используется).
Результаты пересчёта — приближённые, не для геодезических работ.
